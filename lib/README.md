# lib/

Third-party Lua libraries go here (vendored, one folder or file each).

Popular choices for LÖVE:

- hump (`gamestate`, `timer`, `vector`, `class`): https://github.com/vrld/hump
- anim8 (sprite animation): https://github.com/kikito/anim8
- STI (Tiled map loader): https://github.com/karai17/Simple-Tiled-Implementation
- bump.lua (AABB collision): https://github.com/kikito/bump.lua
- lume (utility belt): https://github.com/rxi/lume

Require them as `require("lib.hump.gamestate")` etc.
