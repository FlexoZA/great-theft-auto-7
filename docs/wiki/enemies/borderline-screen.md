# Max's screen

[Wiki](../README.md) / [Enemies](README.md) / borderline

<img src="img/borderline-screen.png" alt="Max's screen" width="240">

Maximum Maximilian Max live, on a giant screen in Hyperbole yellow, TO THE MAX running along the bottom. It doesn't shoot back; the dock and the gun haulers guarding it do.

| | |
|---|---|
| **Where** | Prosperity: one in each corner district's square, up on two legs, a hauler dock guarding it; the north gate stays shut until all four are down |
| **Health** | 450 |
| **A blast** | takes 40 off it |
| **Drops** | nothing: the north gate opens when the last one goes |

## Abilities

- Every one shot down, the rest turn up 35% brighter. The last one down, Max throws the north gate open.

## How to beat it

- Shoot the hauler dock first: it keeps building junk haulers while you're near.
- Rockets and grenades work: anything that touches the panel hurts it.
