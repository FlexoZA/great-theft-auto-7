# Flamethrower

[Wiki](../README.md) / [Weapons](README.md) / Flamethrower

<img src="img/flamethrower.png" alt="flamethrower" width="320">

A jet of fire that sets whoever it touches alight. Short reach; a fuel can fills the tank.

**How to use it:** Drag it into a weapon slot; its number key picks it.
