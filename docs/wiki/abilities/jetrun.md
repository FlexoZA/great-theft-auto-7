# Jet run

[Wiki](../README.md) / [Abilities](README.md) / Jet run

<img src="img/jetrun.png" alt="jet run" width="160">

Fly a strafing run over walls and enemies, rockets dropping behind you. Nothing hits you up there.

**How to use it:** Press its key, then click where to land.
